3. Method 1: TF-IDF

📊 TF-IDF (Term Frequency - Inverse Document Frequency)

Goal: Identify important words in each document by weighing frequency against rarity across documents.

Formula: $$\text{TF-IDF}(t, d) = \text{TF}(t, d) \times \text{IDF}(t) = \frac{f_{t,d}}{\sum_{t' \in d} f_{t',d}} \times \log\frac{N}{df_t}$$

Step 1: Compute Term Frequency (TF)

For Document 1: "The cat sat on the mat. The cat was happy."

Word Count TF (count / total)
the 3 3 / 10 = 0.300
cat 2 2 / 10 = 0.200
sat, on, mat, was, happy 1 each 1 / 10 = 0.100

Step 2: Compute Inverse Document Frequency (IDF)

Word Appears in Docs IDF = log(8 / df)
the 8 / 8 log(8/8) = 0.000
cat 4 / 8 log(8/4) = 0.693
dog 4 / 8 log(8/4) = 0.693
bird 2 / 8 log(8/2) = 1.386
mat 2 / 8 log(8/2) = 1.386
sang 1 / 8 log(8/1) = 2.079

Step 3: TF-IDF for Document 1

Word TF IDF TF-IDF
the 0.300 0.000 0.000
cat 0.200 0.693 0.139
sat 0.100 1.386 0.139
mat 0.100 1.386 0.139
happy 0.100 1.099 0.110

Document 1 Vector (Top 5 Terms)

{ "cat": 0.139, "sat": 0.139, "mat": 0.139, "happy": 0.110, "was": 0.055 }

📌 TF-IDF Insights

  • "the" gets 0.000 because it appears in every document (not discriminative)
  • "cat", "sat", "mat" get high scores (important for this document)
  • Limitation: No semantic meaning—doesn't know "cat" and "dog" are similar
  • Use case: Document search, keyword extraction

4. Method 2: Word2Vec (Skip-Gram with Negative Sampling)

🎯 Skip-Gram with Negative Sampling (SGNS)

Goal: Learn dense vector embeddings where words with similar contexts are close in vector space.

Approach: Predict context words from target word, use negative sampling for efficiency.

Step 1: Generate Training Pairs (Window Size = 2)

From sentence: "The cat sat on the mat"

Target Word Context Words (Window ±2)
cat the, sat (positive); bird, ran (negative samples)
sat the, cat, on (positive); flew, park (negative samples)
mat on, the (positive); bird, sang (negative samples)

Step 2: Training Objective

Maximize probability of seeing real context, minimize for random words:

$$\text{Loss} = -\log \sigma(\mathbf{v}_c \cdot \mathbf{v}_t) - \sum_{i=1}^{k} \log \sigma(-\mathbf{v}_{n_i} \cdot \mathbf{v}_t)$$

Where \(\mathbf{v}_c\) = context vector, \(\mathbf{v}_t\) = target vector, \(\mathbf{v}_{n_i}\) = negative samples

Step 3: Learned Embeddings (Simplified 3D)

After training with embedding dimension = 3:

Word Vector (3D)
cat [0.82, -0.31, 0.47]
dog [0.79, -0.28, 0.54]
bird [0.71, -0.22, 0.66]
mat [-0.15, 0.91, -0.39]
park [-0.12, 0.88, -0.46]
tree [-0.18, 0.85, -0.49]

Step 4: Similarity Analysis

Cosine similarity between word pairs:

Word Pair Cosine Similarity Interpretation
cat ↔ dog 0.92 Very similar (both animals)
cat ↔ bird 0.87 Similar (both animals)
dog ↔ bird 0.90 Similar (both animals)
mat ↔ park 0.98 Very similar (both locations)
cat ↔ mat 0.12 Dissimilar (different semantic groups)

📌 SGNS Insights

  • Dense vectors: Every word gets a fixed-length vector (e.g., 50-300 dimensions)
  • Semantic similarity: "cat", "dog", "bird" cluster together
  • Context-based: Words in similar contexts get similar embeddings
  • Limitation: One embedding per word (can't handle polysemy like "bank")
  • Use case: Text classification, clustering, semantic search

5. Method 3: CBOW (Continuous Bag of Words)

🎒 Continuous Bag of Words (CBOW)

Goal: Same as SGNS (dense embeddings), but reversed: predict target word from context.

Difference from SGNS: CBOW is faster but slightly less accurate; better for frequent words.

Step 1: Generate Training Examples (Window Size = 2)

From sentence: "The cat sat on the mat"

Context Words Target Word
[the, sat] cat
[the, cat, on] sat
[sat, on, the] mat (predict this)

Step 2: Forward Pass Example

To predict "cat" from context [the, sat]:

  1. Get embeddings: \(\mathbf{v}_{\text{the}} = [0.1, 0.3, -0.2]\), \(\mathbf{v}_{\text{sat}} = [0.4, -0.1, 0.5]\)
  2. Average context: \(\mathbf{v}_{\text{context}} = \frac{1}{2}([0.1, 0.3, -0.2] + [0.4, -0.1, 0.5]) = [0.25, 0.10, 0.15]\)
  3. Score all words: \(\text{score}(w) = \mathbf{v}_{\text{context}} \cdot \mathbf{v}_w\)
  4. Apply softmax: \(P(\text{cat} | \text{the, sat}) = \frac{e^{\text{score}(\text{cat})}}{\sum_{w'} e^{\text{score}(w')}}\)

Step 3: Learned Embeddings (3D)

CBOW produces similar embeddings to SGNS, but with slight differences:

Word CBOW Vector (3D) SGNS Vector (3D)
cat [0.84, -0.29, 0.46] [0.82, -0.31, 0.47]
dog [0.81, -0.26, 0.53] [0.79, -0.28, 0.54]
bird [0.73, -0.20, 0.65] [0.71, -0.22, 0.66]

Step 4: SGNS vs. CBOW Comparison

Aspect SGNS (Skip-Gram) CBOW
Prediction Context from target Target from context
Training speed Slower Faster
Rare words Better Worse
Frequent words Good Better
Accuracy Higher Slightly lower

📌 CBOW Insights

  • Context averaging: Smooths out noise from individual context words
  • Faster training: One prediction per example vs. multiple for SGNS
  • Better for common words: "the", "cat", "dog" get better embeddings
  • Limitation: Struggles with rare words (less training signal)
  • Use case: When speed matters and vocabulary is not too large

6. Method 4: GloVe (Global Vectors)

🌍 GloVe: Global Vectors for Word Representation

Goal: Combine global co-occurrence statistics with local context (best of both worlds).

Key idea: Word embeddings should encode ratios of co-occurrence probabilities.

Step 1: Build Co-occurrence Matrix (Window Size = 2)

Count how often word i appears near word j across the entire corpus:

cat dog bird mat park happy
cat 0 3 1 4 0 2
dog 3 0 1 0 5 1
bird 1 1 0 0 0 0
mat 4 0 0 0 0 1
park 0 5 0 0 0 0

Step 2: GloVe Objective Function

Minimize the weighted least squares loss:

$$J = \sum_{i,j=1}^{V} f(X_{ij}) \left( \mathbf{w}_i^T \mathbf{w}_j + b_i + b_j - \log X_{ij} \right)^2$$

Where:

  • \(X_{ij}\) = co-occurrence count of words i and j
  • \(\mathbf{w}_i, \mathbf{w}_j\) = word vectors to learn
  • \(b_i, b_j\) = bias terms
  • \(f(X_{ij})\) = weighting function (caps at 100 to prevent overweighting common pairs)

Step 3: Co-occurrence Ratios (Key Insight)

GloVe learns from ratios of co-occurrence probabilities:

Word Pair P(mat | cat) P(mat | dog) Ratio Meaning
cat → mat 4/10 = 0.40 0/10 = 0.00 ∞ "mat" strongly associated with "cat"
dog → park 0/10 = 0.00 5/10 = 0.50 0 "park" strongly associated with "dog"
cat/dog → animals 0.20 0.20 1.0 Both equally associated with "animals"

Step 4: Learned Embeddings (3D)

Word GloVe Vector (3D)
cat [0.85, -0.30, 0.43]
dog [0.83, -0.27, 0.49]
bird [0.76, -0.21, 0.61]
mat [-0.14, 0.93, -0.34]
park [-0.11, 0.90, -0.42]

📌 GloVe Insights

  • Global statistics: Uses entire corpus co-occurrence matrix (unlike Word2Vec's local windows)
  • Deterministic: Given the same data, produces same embeddings (Word2Vec is stochastic)
  • Faster convergence: Often trains faster than Word2Vec on large corpora
  • Better on word analogies: "king - man + woman = queen" works better with GloVe
  • Limitation: Requires building full co-occurrence matrix (memory intensive)
  • Use case: When you have enough RAM and want stable, reproducible embeddings

Method Comparison Summary

Method Representation Semantic Capture Training Data Best Use Case
TF-IDF Sparse vectors (vocab size) ❌ None (just frequency) Minimal Document search, keyword extraction
SGNS Dense vectors (50-300D) ✅ Strong (context-based) Large corpus Rare words, semantic similarity
CBOW Dense vectors (50-300D) ✅ Strong (context-based) Large corpus Frequent words, fast training
GloVe Dense vectors (50-300D) ✅ Strongest (global stats) Large corpus Word analogies, reproducibility

TF-IDF

Pros:

  • Simple, fast, interpretable
  • No training required
  • Works with small data

Cons:

  • No semantic understanding
  • Sparse, high-dimensional
  • Can't capture synonymy

SGNS

Pros:

  • Captures semantics
  • Dense, efficient
  • Great for rare words

Cons:

  • Requires large corpus
  • Slower than CBOW
  • Stochastic (non-reproducible)

CBOW

Pros:

  • Faster than SGNS
  • Better for common words
  • Smooths noise

Cons:

  • Worse for rare words
  • Slightly less accurate
  • Requires large corpus

GloVe

Pros:

  • Best for word analogies
  • Deterministic
  • Faster convergence

Cons:

  • Memory-intensive
  • Requires co-occurrence matrix
  • More complex implementation

🎯 When to Use Which Method?

  • TF-IDF: Quick and dirty document similarity, no ML infrastructure
  • SGNS: General-purpose embeddings, especially if vocabulary has rare words
  • CBOW: When training speed matters and vocabulary is dominated by common words
  • GloVe: When you need reproducible embeddings and have RAM for co-occurrence matrix
  • Modern approach: Use pre-trained contextual embeddings (BERT, GPT) for best results!
