Advanced POS Tagging Models

Forward Algorithm • MEMM • CRF • BiLSTM • BERT

💡 Intuition

Why we need models beyond basic HMMs for POS tagging

Recap: POS Tagging as Sequence Labeling

In Part 1, we learned that POS tagging assigns a grammatical label (noun, verb, adjective, etc.) to every word in a sentence. We modeled this with Hidden Markov Models (HMMs), which use transition probabilities between tags and emission probabilities from tags to words.

But HMMs have significant limitations. This page explores the evolution of POS tagging models that overcome those limitations:

Rule-Based

Hand-crafted rules like "a word ending in -ly is an adverb." Brittle but interpretable.

Statistical (HMM)

Generative model: learns P(words, tags). Uses Viterbi for decoding. ~95% accuracy.

Discriminative (MEMM/CRF)

Models P(tags | words) directly. Rich features. ~96–97% accuracy.

Neural (BiLSTM, BERT)

Learns features automatically from data. Bidirectional context. ~97.5–98% accuracy.

Why HMMs Aren't Enough

  • Independence assumption: HMMs assume the observed word depends only on the current tag. It cannot look at neighboring words, word shape, prefixes, or suffixes.
  • Generative vs. discriminative: HMMs model the joint P(words, tags), but we only need the conditional P(tags | words). Discriminative models are more direct and often more accurate.
  • Limited context: Standard HMMs use only bigram tag context (previous tag). They cannot use the word two positions back, or the word two positions ahead.

🔍 The Bidirectional Reading Analogy

Imagine reading a sentence left-to-right and encountering the word "bank." You might guess it's a financial institution. But if you could also peek ahead and see "...of the river," you'd instantly know it's a river bank. Reading forwards AND backwards gives more context—and that's the key insight behind bidirectional models.

✏️ Try It Yourself!

Consider: "The old man the boats."

A forward-only model might tag "old" as JJ (adjective) and "man" as NN (noun). But the correct parse has "old" as NN (noun, meaning "elderly people") and "man" as VB (verb, meaning "to operate"). What information from the right context would help a bidirectional model get this right?

Solution: Seeing "the boats" at the end reveals that something must be a verb governing "boats" as its object. A bidirectional model reading backwards would recognize that "man" needs to be a verb for the sentence to be grammatical, and "old" must therefore be a noun (subject).

📊 The Forward Algorithm

Computing the likelihood of an observation sequence efficiently

The Problem: P(O|λ)

Given an HMM λ = (A, B, π) and an observation sequence O = o1, o2, ..., oT, how do we compute the total probability of seeing that sequence? This is the evaluation problem—one of the three fundamental HMM problems.

The Naive Approach: Exponential Complexity

We could enumerate every possible state sequence Q = q1, ..., qT and sum:

Naive Computation
\[ P(O|\lambda) = \sum_{\text{all } Q} P(O|Q, \lambda) \cdot P(Q|\lambda) \]

With N hidden states and T observations, there are NT possible state sequences. For N=10 states and T=20 words, that's 1020 sequences—completely intractable!

The Forward Variable

The forward variable αt(j) captures the probability of having seen the first t observations and being in state j at time t:

Forward Variable Definition
\[ \alpha_t(j) = P(o_1, o_2, \ldots, o_t, \; q_t = j \mid \lambda) \]

The Three Steps

1. Initialization (t = 1)
\[ \alpha_1(j) = \pi_j \cdot b_j(o_1) \]

The probability of starting in state j (πj) times the probability of state j emitting the first observation (bj(o1)).

2. Recursion (t = 2, ..., T)
\[ \alpha_t(j) = \left[ \sum_{i=1}^{N} \alpha_{t-1}(i) \cdot a_{ij} \right] \cdot b_j(o_t) \]

Sum over all states i that could have been the previous state: take αt-1(i) (probability of being in state i at t-1), multiply by aij (transition probability from i to j), then multiply by bj(ot) (emission probability).

3. Termination
\[ P(O|\lambda) = \sum_{j=1}^{N} \alpha_T(j) \]

The total sequence probability is the sum of all forward variables at the final time step.

Complexity: O(N²T) vs O(NT)

The Forward Algorithm reuses intermediate computations (dynamic programming). At each of T time steps, we compute N states, each requiring a sum over N previous states: O(N²T)—polynomial instead of exponential.

Worked Example

Let's use a weather/ice cream example with 2 states (Hot, Cold) and 3 observations (3, 1, 3 ice creams eaten):

  • States: Hot (H), Cold (C)
  • π = [0.8, 0.2] (start probabilities)
  • Transition matrix A: aHH=0.6, aHC=0.4, aCH=0.5, aCC=0.5
  • Emission B: bH(1)=0.2, bH(2)=0.4, bH(3)=0.4; bC(1)=0.5, bC(2)=0.4, bC(3)=0.1

Observation sequence: O = (3, 1, 3)

Step 1: Initialization (t=1, o1=3)

  • α1(H) = πH · bH(3) = 0.8 × 0.4 = 0.32
  • α1(C) = πC · bC(3) = 0.2 × 0.1 = 0.02

Step 2: Recursion (t=2, o2=1)

  • α2(H) = [α1(H)·aHH + α1(C)·aCH] · bH(1) = [0.32×0.6 + 0.02×0.5] × 0.2 = [0.192 + 0.01] × 0.2 = 0.0404
  • α2(C) = [α1(H)·aHC + α1(C)·aCC] · bC(1) = [0.32×0.4 + 0.02×0.5] × 0.5 = [0.128 + 0.01] × 0.5 = 0.069

Step 3: Recursion (t=3, o3=3)

  • α3(H) = [0.0404×0.6 + 0.069×0.5] × 0.4 = [0.02424 + 0.0345] × 0.4 = 0.02350
  • α3(C) = [0.0404×0.4 + 0.069×0.5] × 0.1 = [0.01616 + 0.0345] × 0.1 = 0.005066

Termination

P(O|λ) = α3(H) + α3(C) = 0.02350 + 0.005066 = 0.02856

🔍 Viterbi Decoding

Finding the single best state sequence

Forward vs. Viterbi: Sum vs. Max

The Forward Algorithm sums over all paths to get the total probability. The Viterbi Algorithm maximizes to find the single most likely state sequence. The structure is identical—only the aggregation operation changes.

AspectForward AlgorithmViterbi Algorithm
GoalP(O|λ) — total likelihoodBest state sequence Q*
OperationSum (Σ)Max
BacktrackingNot neededBackpointers required
ComplexityO(N²T)O(N²T)
Use caseModel evaluation, trainingDecoding (tagging)

Viterbi Formulas

Viterbi Variable
\[ v_t(j) = \max_{i} \left[ v_{t-1}(i) \cdot a_{ij} \right] \cdot b_j(o_t) \]

Instead of summing over all previous states, we take the maximum. This gives the probability of the best path ending in state j at time t.

Backpointer
\[ bt_t(j) = \arg\max_{i} \left[ v_{t-1}(i) \cdot a_{ij} \right] \]

We also record which previous state gave the maximum. After reaching the end, we trace back through these pointers to recover the best path.

Log-Space Computation

In practice, multiplying many small probabilities leads to numerical underflow (values too small for floating-point). The solution: work in log space.

Viterbi in Log Space
\[ \log v_t(j) = \max_{i} \left[ \log v_{t-1}(i) + \log a_{ij} \right] + \log b_j(o_t) \]

Multiplications become additions, which are numerically stable. The argmax is unchanged since log is monotonic.

Worked Example

Using the same weather HMM and O = (3, 1, 3):

Initialization (t=1, o=3)

  • v1(H) = 0.8 × 0.4 = 0.32
  • v1(C) = 0.2 × 0.1 = 0.02

t=2, o=1

  • v2(H) = max(0.32×0.6, 0.02×0.5) × 0.2 = max(0.192, 0.01) × 0.2 = 0.192 × 0.2 = 0.0384, bt=H
  • v2(C) = max(0.32×0.4, 0.02×0.5) × 0.5 = max(0.128, 0.01) × 0.5 = 0.128 × 0.5 = 0.064, bt=H

t=3, o=3

  • v3(H) = max(0.0384×0.6, 0.064×0.5) × 0.4 = max(0.02304, 0.032) × 0.4 = 0.032 × 0.4 = 0.0128, bt=C
  • v3(C) = max(0.0384×0.4, 0.064×0.5) × 0.1 = max(0.01536, 0.032) × 0.1 = 0.032 × 0.1 = 0.0032, bt=C

Backtrace

Best final state: H (0.0128 > 0.0032). Trace back: t=3→H, bt=C; t=2→C, bt=H; t=1→H.

Best path: H → C → H

⚠️ Greedy vs. Viterbi

Picking the most likely state at each time step independently (greedy) can give a different answer than Viterbi. Greedy ignores transition probabilities between consecutive choices. The Viterbi path is globally optimal, not just locally optimal at each step.

⚙️ Maximum Entropy Markov Model

Discriminative sequence labeling with rich features

Motivation: Limitations of HMMs

HMMs model P(words, tags) generatively. This means:

  • The emission probability bj(ot) depends only on the current tag—we cannot condition on neighboring words, word shape, prefixes, or any other features.
  • Adding features requires changing the model structure entirely.

MEMMs flip the script: they model P(tagi | tagi-1, observation) directly, and can incorporate arbitrary features.

Generative vs. Discriminative

AspectGenerative (HMM)Discriminative (MEMM)
ModelsP(words, tags) = P(tags) · P(words|tags)P(tags | words) directly
FeaturesOnly word identityArbitrary: suffixes, shape, neighbors, etc.
IndependenceWords independent given tagsNo such assumption needed
TrainingCount-based (MLE)Logistic regression / MaxEnt
Unknown wordsRequires smoothing hacksFeature-based: handles naturally

The MEMM Model

At each position i, the MEMM models:

MEMM Local Classifier
\[ P(t_i \mid t_{i-1}, o) = \frac{\exp\left(\mathbf{w} \cdot \mathbf{f}(t_i, t_{i-1}, o)\right)}{\sum_{t'} \exp\left(\mathbf{w} \cdot \mathbf{f}(t', t_{i-1}, o)\right)} \]

This is a softmax (maximum entropy) classifier. f is a feature vector, w is a learned weight vector. The normalization is local—per position.

Feature Engineering

The power of MEMMs comes from rich features. Common POS tagging features include:

  • Current word: wi = "running"
  • Previous tag: ti-1 = VBD
  • Word suffixes: -ing, -ed, -ly, -tion, -ness
  • Word prefixes: un-, re-, pre-
  • Word shape: Xx (capitalized), XXXX (all caps), x.x (abbreviation with period)
  • Capitalization: is_capitalized, is_all_caps, is_mixed_case
  • Neighboring words: wi-1, wi+1
  • Contains digit: has_digit, is_number
  • Contains hyphen: is_hyphenated

✅ Feature Example

For the word "running" with previous tag VBD:

  • f1: word="running" & tag=VBG → 1
  • f2: suffix="-ing" & tag=VBG → 1
  • f3: prev_tag=VBD & tag=VBG → 1
  • f4: is_lowercase & tag=VBG → 1

The model learns weights for thousands of such features from training data.

The Label Bias Problem

MEMMs have a critical flaw: label bias. Because normalization is local (per state), states with few outgoing transitions effectively ignore observations.

⚠️ Label Bias Explained

Imagine a state that can only transition to one other state. No matter what word is observed, all probability mass goes to that single successor. The observation is ignored. This happens because the probabilities must sum to 1 at each state, and if there's only one option, it gets all the mass. CRFs solve this with global normalization.

✏️ Try It Yourself!

Design a feature set for tagging the unknown word "unforgettable". What features would help a MEMM correctly tag it as JJ (adjective)?

Useful features:

  • prefix="un-": common adjective prefix (unhappy, unusual, unlikely)
  • suffix="-able": strong indicator of adjective (readable, comfortable)
  • word_length > 10: longer words are often adjectives or nouns
  • contains no digits/hyphens: rules out number/compound
  • is_lowercase: not a proper noun
  • prev_word context: if preceded by "is" or "an", strongly suggests JJ

↔️ Bidirectionality & CRFs

Using full context and global normalization

Why Left-to-Right Isn't Enough

Consider these sentences where right context is crucial:

  • "The lead paint was dangerous." — "lead" is JJ (adjective), but only "paint" tells us that.
  • "Please record the results." vs. "This is a record." — The word after "record" disambiguates verb vs. noun.
  • "The old man the boats." — Only "the boats" at the end reveals "man" is a verb.

Bidirectional Approaches

A bidirectional model runs two passes:

  1. Forward pass: processes the sentence left-to-right
  2. Backward pass: processes the sentence right-to-left

The predictions combine information from both directions at each position.

Conditional Random Fields (CRFs)

CRFs solve both the label bias problem and the directionality limitation. They use global normalization over the entire sequence:

Linear-Chain CRF
\[ P(\mathbf{y}|\mathbf{x}) = \frac{1}{Z(\mathbf{x})} \exp\left( \sum_{t=1}^{T} \sum_{k} \lambda_k f_k(y_t, y_{t-1}, \mathbf{x}, t) \right) \]

Where Z(x) is the partition function (normalization constant) that sums over all possible tag sequences:

Partition Function
\[ Z(\mathbf{x}) = \sum_{\mathbf{y}'} \exp\left( \sum_{t=1}^{T} \sum_{k} \lambda_k f_k(y'_t, y'_{t-1}, \mathbf{x}, t) \right) \]

This global normalization means the model considers the entire sequence when making predictions, avoiding label bias.

HMM vs. MEMM vs. CRF

PropertyHMMMEMMCRF
TypeGenerativeDiscriminativeDiscriminative
ModelsP(x, y)P(yt|yt-1, x)P(y|x)
NormalizationGlobal (generative)Local (per state)Global (over sequence)
FeaturesLimitedRich, arbitraryRich, arbitrary
Label biasNoYes (problematic)No
Typical accuracy~95%~96%~97%

🧠 Neural Network Models

From handcrafted features to learned representations

Word Embeddings as Input

Instead of discrete word identities, neural taggers use dense word embeddings (see Word2Vec guide). Each word wt is represented as a vector xt ∈ ℝd that captures semantic and syntactic properties.

Window-Based Feedforward Tagger

The simplest neural approach: concatenate embeddings of the target word and its neighbors (e.g., a 5-word window), feed into a feedforward network, and predict the tag with softmax. This is simple but limited—fixed window size means limited context.

BiLSTM Tagger

The Bidirectional LSTM processes the entire sentence in both directions:

BiLSTM Architecture
\[ \vec{h}_t = \text{LSTM}_f(x_t, \vec{h}_{t-1}) \] \[ \overleftarrow{h}_t = \text{LSTM}_b(x_t, \overleftarrow{h}_{t+1}) \] \[ \hat{y}_t = \text{softmax}(W \cdot [\vec{h}_t ; \overleftarrow{h}_t] + b) \]

The forward LSTM reads left-to-right; the backward LSTM reads right-to-left. Their hidden states are concatenated [;] at each position, giving a representation that captures full bidirectional context. A linear layer + softmax produces tag probabilities.

BiLSTM-CRF

Adding a CRF layer on top of the BiLSTM combines the best of both worlds:

  • BiLSTM: Learns rich contextual representations automatically
  • CRF layer: Enforces valid tag transition constraints (e.g., I-PER shouldn't follow B-LOC) and optimizes the whole sequence jointly

The CRF uses BiLSTM outputs as emission scores and learns transition scores between tags. Decoding uses Viterbi over these combined scores.

Transformer-Based Taggers

Self-attention allows each word to attend to all other words simultaneously—no sequential bottleneck. Pre-trained models like BERT capture deep contextual knowledge:

  1. Take a pre-trained BERT model
  2. Add a simple linear classification layer on top
  3. Fine-tune on POS tagging data

BERT's bidirectional attention across all layers gives it extremely rich representations for each token.

Trace through a BiLSTM for the sentence "I can fly" (3 words). Assume embedding dimension d=2 and hidden size h=2. The forward LSTM processes "I" → "can" → "fly"; the backward LSTM processes "fly" → "can" → "I". What dimension is the concatenated representation at each position?

Each LSTM produces a hidden vector of dimension h=2. At each position:

  • Forward hidden: &vec;ht ∈ ℝ2
  • Backward hidden: ←ht ∈ ℝ2
  • Concatenated: [&vec;ht; ←ht] ∈ ℝ4

So the classification layer W has shape (num_tags × 4). For "can" at position 2, &vec;h2 encodes "I can" (left context) and ←h2 encodes "can fly" (right context)—both directions help disambiguate "can" as a modal verb.

🐍 Python Implementations

Forward Algorithm, MEMM, and BiLSTM tagger code

Forward Algorithm

import numpy as np
from typing import Dict, List, Tuple


class ForwardAlgorithm:
    """Compute P(O|lambda) using the Forward Algorithm."""

    def __init__(self, states: List[str], obs: List[str],
                 pi: Dict[str, float], A: Dict[str, Dict[str, float]],
                 B: Dict[str, Dict[str, float]]):
        """Args:
            states: Hidden state labels.
            obs: Observation vocabulary.
            pi: Initial state probabilities.
            A: Transition probabilities A[i][j] = P(j|i).
            B: Emission probabilities B[state][obs].
        """
        self.states = states
        self.pi = pi
        self.A = A
        self.B = B

    def forward(self, observations: List[str]) -> Tuple[float, List[Dict[str, float]]]:
        """Compute forward variables and total probability.

        Args:
            observations: Sequence of observed symbols.

        Returns:
            Tuple of (total probability, list of alpha dicts per time step).
        """
        T = len(observations)
        alpha: List[Dict[str, float]] = []

        # Initialization
        a0 = {}
        for s in self.states:
            a0[s] = self.pi[s] * self.B[s][observations[0]]
        alpha.append(a0)

        # Recursion
        for t in range(1, T):
            at = {}
            for j in self.states:
                at[j] = sum(
                    alpha[t - 1][i] * self.A[i][j]
                    for i in self.states
                ) * self.B[j][observations[t]]
            alpha.append(at)

        # Termination
        total = sum(alpha[T - 1][s] for s in self.states)
        return total, alpha


# Usage example
fa = ForwardAlgorithm(
    states=['H', 'C'],
    obs=['1', '2', '3'],
    pi={'H': 0.8, 'C': 0.2},
    A={'H': {'H': 0.6, 'C': 0.4}, 'C': {'H': 0.5, 'C': 0.5}},
    B={'H': {'1': 0.2, '2': 0.4, '3': 0.4},
       'C': {'1': 0.5, '2': 0.4, '3': 0.1}}
)
prob, alphas = fa.forward(['3', '1', '3'])
print(f"P(O|lambda) = {prob:.6f")  # ≈ 0.02856

MEMM Tagger

from sklearn.linear_model import LogisticRegression
from typing import Dict, List, Optional
import numpy as np


class MEMMTagger:
    """Maximum Entropy Markov Model for POS tagging."""

    def __init__(self):
        self.model: Optional[LogisticRegression] = None
        self.tag_set: List[str] = []
        self.word_set: set = set()

    def extract_features(self, word: str, prev_tag: str,
                          prev_word: str, next_word: str) -> Dict[str, float]:
        """Extract features for a word in context.

        Args:
            word: Current word.
            prev_tag: Previous POS tag.
            prev_word: Previous word.
            next_word: Next word.

        Returns:
            Feature dictionary.
        """
        features = {
            f'word={word.lower()}': 1.0,
            f'prev_tag={prev_tag}': 1.0,
            f'suffix_3={word[-3:]}': 1.0 if len(word) >= 3 else 0.0,
            f'suffix_2={word[-2:]}': 1.0 if len(word) >= 2 else 0.0,
            'is_capitalized': 1.0 if word[0].isupper() else 0.0,
            'is_all_caps': 1.0 if word.isupper() else 0.0,
            'has_digit': 1.0 if any(c.isdigit() for c in word) else 0.0,
            'has_hyphen': 1.0 if '-' in word else 0.0,
            f'prev_word={prev_word.lower()}': 1.0,
            f'next_word={next_word.lower()}': 1.0,
            'is_unknown': 0.0 if word.lower() in self.word_set else 1.0,
        }
        return features

    def train(self, tagged_sentences: List[List[tuple]]) -> None:
        """Train the MEMM on tagged data.

        Args:
            tagged_sentences: List of sentences, each a list of (word, tag) tuples.
        """
        # Collect vocabulary and tags
        for sent in tagged_sentences:
            for word, tag in sent:
                self.word_set.add(word.lower())
                if tag not in self.tag_set:
                    self.tag_set.append(tag)

        # Extract features and labels
        X_dicts, y = [], []
        for sent in tagged_sentences:
            for i, (word, tag) in enumerate(sent):
                prev_tag = sent[i - 1][1] if i > 0 else '<START>'
                prev_word = sent[i - 1][0] if i > 0 else '<s>'
                next_word = sent[i + 1][0] if i < len(sent) - 1 else '</s>'
                X_dicts.append(self.extract_features(word, prev_tag, prev_word, next_word))
                y.append(tag)

        # Vectorize features
        from sklearn.feature_extraction import DictVectorizer
        self.vectorizer = DictVectorizer(sparse=True)
        X = self.vectorizer.fit_transform(X_dicts)

        self.model = LogisticRegression(max_iter=1000, C=1.0)
        self.model.fit(X, y)

    def predict(self, words: List[str]) -> List[str]:
        """Tag a sentence using greedy left-to-right decoding.

        Args:
            words: List of words to tag.

        Returns:
            List of predicted POS tags.
        """
        tags = []
        prev_tag = '<START>'
        for i, word in enumerate(words):
            prev_word = words[i - 1] if i > 0 else '<s>'
            next_word = words[i + 1] if i < len(words) - 1 else '</s>'
            feats = self.extract_features(word, prev_tag, prev_word, next_word)
            X = self.vectorizer.transform([feats])
            tag = self.model.predict(X)[0]
            tags.append(tag)
            prev_tag = tag
        return tags

BiLSTM-CRF Tagger (PyTorch Sketch)

import torch
import torch.nn as nn
from typing import List, Dict


class BiLSTMCRFTagger(nn.Module):
    """BiLSTM-CRF model for POS tagging.

    Args:
        vocab_size: Size of word vocabulary.
        tag_to_ix: Mapping from tag string to index.
        embedding_dim: Dimension of word embeddings.
        hidden_dim: Dimension of LSTM hidden state.
    """

    def __init__(self, vocab_size: int, tag_to_ix: Dict[str, int],
                 embedding_dim: int = 100, hidden_dim: int = 128):
        super().__init__()
        self.tag_to_ix = tag_to_ix
        self.tagset_size = len(tag_to_ix)
        self.hidden_dim = hidden_dim

        self.embedding = nn.Embedding(vocab_size, embedding_dim)
        self.lstm = nn.LSTM(embedding_dim, hidden_dim // 2,
                            bidirectional=True, batch_first=True)
        self.hidden2tag = nn.Linear(hidden_dim, self.tagset_size)

        # CRF transition parameters: transitions[i][j] = score of j -> i
        self.transitions = nn.Parameter(
            torch.randn(self.tagset_size, self.tagset_size)
        )

    def _get_lstm_features(self, sentence: torch.Tensor) -> torch.Tensor:
        """Get emission scores from BiLSTM.

        Args:
            sentence: Tensor of word indices, shape (1, seq_len).

        Returns:
            Emission scores, shape (seq_len, tagset_size).
        """
        embeds = self.embedding(sentence)
        lstm_out, _ = self.lstm(embeds)
        emissions = self.hidden2tag(lstm_out.squeeze(0))
        return emissions

    def _viterbi_decode(self, emissions: torch.Tensor) -> List[int]:
        """Find best tag sequence using Viterbi on CRF.

        Args:
            emissions: Emission scores (seq_len, tagset_size).

        Returns:
            List of best tag indices.
        """
        seq_len = emissions.size(0)
        viterbi = emissions[0]
        backpointers: List[torch.Tensor] = []

        for t in range(1, seq_len):
            scores = viterbi.unsqueeze(1) + self.transitions
            max_scores, bp = scores.max(dim=0)
            viterbi = max_scores + emissions[t]
            backpointers.append(bp)

        best_last = viterbi.argmax().item()
        best_path = [best_last]
        for bp in reversed(backpointers):
            best_path.append(bp[best_path[-1]].item())
        best_path.reverse()
        return best_path

    def forward(self, sentence: torch.Tensor) -> List[int]:
        """Tag a sentence.

        Args:
            sentence: Tensor of word indices.

        Returns:
            List of predicted tag indices.
        """
        emissions = self._get_lstm_features(sentence)
        return self._viterbi_decode(emissions)
