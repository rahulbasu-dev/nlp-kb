Skip-gram with Negative Sampling

Learn how neural networks learn word embeddings from context

What is SGNS?

Skip-gram with Negative Sampling (SGNS) is a neural approach that learns word embeddings by predicting context words from target words, trained efficiently using negative sampling.

Learns patterns

How SGNS Works

1 Context Window

Slide a window over the text. For each word, we want to predict the surrounding words.

... the | cat | sat ...
2 Positive Pairs

Create training pairs: (target_word, context_word). These should have HIGH similarity.

(cat, the), (cat, sat)
3 Negative Sampling

Randomly sample words that DON'T appear in context. These should have LOW similarity.

(cat, programming), (cat, moon)
4 Gradient Descent

Train embeddings to satisfy all pairs. This is 100x faster than full softmax!

O(k) not O(V)

Key Concepts

Instead of computing softmax over all V vocabulary words (slow!), we only compute loss for k negative samples. This reduces complexity from O(V) to O(k), making training 100x+ faster.

A word embedding captures semantic and syntactic properties. Words with similar meaning should be close in vector space. The beauty of SGNS is it learns this automatically from context!

Window size 2-5 usually works well. Larger windows capture broader topical similarity, smaller windows capture more syntactic relationships. Experiment for your corpus!
