1. Intuition: What Are Neural Networks?

Historical Context (Jurafsky & Martin, 2026, p. 128)

Neural networks evolved from the McCulloch-Pitts neuron (1943), a simplified model of biological computation. Modern feedforward networks stack layers of these units, with backpropagation enabling learning via gradient descent.

A neural network is a computational model inspired by how biological neurons in the brain process information. At its core, it's a pattern recognition machine that learns to map inputs to outputs through examples.

🧠 The Brain Analogy

Just as your brain has billions of interconnected neurons that fire in patterns to recognize faces, understand language, or control movement, artificial neural networks use interconnected mathematical "neurons" (nodes) that learn patterns in data. Each connection has a weight that determines how strongly one neuron influences another—similar to synaptic strength in biological neurons.

First modeled by: McCulloch & Pitts (1943)[1], formalized as the perceptron by Rosenblatt (1958)[2]. (See Jurafsky & Martin, 2026, p. 128 for historical overview)

How Neural Networks Learn

Neural networks learn through supervised learning:

  1. Start with random guesses: Initialize weights randomly
  2. Make predictions: Feed input data through the network
  3. Measure error: Compare predictions to true labels
  4. Adjust weights: Use backpropagation[3] to reduce error
  5. Repeat: Iterate thousands of times until accurate

📧 Example: Spam Detection

Input: Email text (converted to numbers representing word frequencies)

Hidden layers: Learn patterns like "free money" + "click now" = suspicious

Output: Probability the email is spam (0.0 = not spam, 1.0 = spam)

After training on thousands of labeled emails, the network learns which word combinations indicate spam, even for emails it's never seen before!

Input → Hidden → Output Flow

Input Layer: Raw features (pixels, words, numbers)

Hidden Layers: Learn progressively abstract patterns

  • Layer 1: Edges and textures
  • Layer 2: Shapes and parts
  • Layer 3: Complex objects

Output Layer: Final prediction (class, number, etc.)

Learning by Trial and Error

Forward Pass: Make a prediction with current weights

Loss Calculation: How wrong was the prediction?

Backpropagation: Calculate how to adjust each weight

Gradient Descent: Update weights to reduce error

Repeat: Each iteration (epoch) improves accuracy

💡 Key Concepts

  • Neuron (Node): Computes weighted sum + bias, then applies activation function
  • Weight: Connection strength between neurons (learned during training)
  • Bias: Shifts activation threshold (like a y-intercept)
  • Activation Function: Introduces non-linearity (e.g., sigmoid, ReLU)
  • Epoch: One complete pass through all training data
  • Learning Rate: Step size for weight updates (too big = unstable, too small = slow)

📋 Network Parameters

Mean Squared Error (Regression)

$$\mathcal{L}(\hat{y}, y) = \frac{1}{n} \sum_{i=1}^{n} (\hat{y}_i - y_i)^2$$

Gradient:

$$\frac{\partial \mathcal{L}}{\partial \hat{y}} = \frac{2}{n}(\hat{y} - y)$$

Use case: Predicting continuous values (house prices, temperatures)

Binary Cross-Entropy (Classification)

$$\mathcal{L}(\hat{y}, y) = -\left[y \log(\hat{y}) + (1-y) \log(1-\hat{y})\right]$$

Gradient:

$$\frac{\partial \mathcal{L}}{\partial \hat{y}} = -\frac{y}{\hat{y}} + \frac{1-y}{1-\hat{y}}$$

Derivation from Maximum Likelihood:

Assuming \(\hat{y}\) represents \(P(y=1 | x)\), the likelihood is:

$$P(y | \hat{y}) = \hat{y}^y (1 - \hat{y})^{1-y}$$

Taking negative log-likelihood gives us the cross-entropy loss.

Why better than MSE for classification? Cross-entropy provides stronger gradients when predictions are confident but wrong, leading to faster convergence.

4.4 Backpropagation (Chain Rule)

Backpropagation[3] computes gradients efficiently using the chain rule of calculus, propagating errors backward through the network.

Output Layer Error

$$\delta^{[L]} = (a^{[L]} - y) \odot \sigma'(z^{[L]})$$

Where:

  • \(\delta^{[L]}\) is the error at the output layer
  • \(a^{[L]}\) is the predicted output
  • \(y\) is the true label
  • \(\odot\) denotes element-wise multiplication
Hidden Layer Error (Recursive Backpropagation)

For layer \(l = L-1, L-2, \ldots, 1\):

$$\delta^{[l]} = \left(W^{[l+1]T} \delta^{[l+1]}\right) \odot \sigma'(z^{[l]})$$

Intuition: The error at layer \(l\) is the weighted sum of errors from layer \(l+1\), scaled by how much the neurons in layer \(l\) contributed to those errors.

Weight and Bias Gradients

$$\frac{\partial \mathcal{L}}{\partial W^{[l]}} = \delta^{[l]} (a^{[l-1]})^T$$

$$\frac{\partial \mathcal{L}}{\partial b^{[l]}} = \delta^{[l]}$$

Note: For mini-batch training with \(m\) samples, average the gradients:

$$\frac{\partial \mathcal{L}}{\partial W^{[l]}} = \frac{1}{m} \sum_{i=1}^{m} \delta^{[l](i)} (a^{[l-1](i)})^T$$

💡 Computational Graph Perspective

Think of the neural network as a computational graph where each operation (matrix multiply, addition, activation) is a node. Backpropagation traverses this graph backward, applying the chain rule at each node:

$$\frac{\partial \mathcal{L}}{\partial w} = \frac{\partial \mathcal{L}}{\partial a} \cdot \frac{\partial a}{\partial z} \cdot \frac{\partial z}{\partial w}$$

Modern deep learning frameworks (PyTorch, TensorFlow) automatically compute these gradients using automatic differentiation.

4.5 Gradient Descent

Parameter Update Rule

$$W := W - \alpha \frac{\partial \mathcal{L}}{\partial W}$$

$$b := b - \alpha \frac{\partial \mathcal{L}}{\partial b}$$

Where:

  • \(\alpha\) is the learning rate (step size)
  • \(\frac{\partial \mathcal{L}}{\partial W}\) is the gradient of the loss with respect to weights
Gradient Descent Variants
Method Batch Size Pros Cons
Batch GD All samples Stable convergence, exact gradient Slow for large datasets, can get stuck in local minima
Stochastic GD 1 sample Fast updates, can escape local minima Noisy updates, unstable
Mini-batch GD 32-512 samples Balance of speed and stability, GPU-efficient Hyperparameter (batch size) to tune

Advanced Optimizers

Momentum

$$v_t = \beta v_{t-1} + (1 - \beta) \nabla_W \mathcal{L}$$

$$W := W - \alpha v_t$$

Effect: Accelerates convergence by accumulating gradients in consistent directions (like a ball rolling downhill).

Adam (Adaptive Moment Estimation)[6]

$$m_t = \beta_1 m_{t-1} + (1 - \beta_1) \nabla_W \mathcal{L}$$ (momentum)

$$v_t = \beta_2 v_{t-1} + (1 - \beta_2) (\nabla_W \mathcal{L})^2$$ (adaptive learning rate)

$$W := W - \alpha \frac{m_t}{\sqrt{v_t} + \epsilon}$$

Why it's popular: Combines momentum with adaptive learning rates per parameter. Works well with default hyperparameters (\(\beta_1 = 0.9, \beta_2 = 0.999\)).

4. Simple Numerical Examples

Minimal Network: 2 Inputs → 2 Hidden → 1 Output

Let's walk through one complete training iteration (forward pass + backward pass + weight update) with concrete numbers.

Initial Setup

Network Architecture:

  • Input layer: 2 neurons (x₁, x₂)
  • Hidden layer: 2 neurons (h₁, h₂)
  • Output layer: 1 neuron (ŷ)

Training Sample:

  • Input: X = [1.0, 0.5]
  • Target: y = 1.0
  • Learning rate: α = 0.1
Initial Weights and Biases
Parameter Value
W₁ (Input → Hidden) [[0.5, 0.2], [-0.3, 0.4]]
b₁ (Hidden bias) [0.1, -0.1]
W₂ (Hidden → Output) [[0.6], [-0.1]]
b₂ (Output bias) [0.2]

Step 1: Forward Pass - Hidden Layer

Linear Transformation (z₁ = X · W₁ + b₁)

$$\mathbf{z}_1 = \begin{bmatrix} 1.0 & 0.5 \end{bmatrix} \cdot \begin{bmatrix} 0.5 & 0.2 \\ -0.3 & 0.4 \end{bmatrix} + \begin{bmatrix} 0.1 & -0.1 \end{bmatrix}$$

Calculation:

  • z₁[0] = (1.0 × 0.5) + (0.5 × -0.3) + 0.1 = 0.5 - 0.15 + 0.1 = 0.45
  • z₁[1] = (1.0 × 0.2) + (0.5 × 0.4) - 0.1 = 0.2 + 0.2 - 0.1 = 0.30

$$\mathbf{z}_1 = \begin{bmatrix} 0.45 & 0.30 \end{bmatrix}$$

Activation Function (a₁ = sigmoid(z₁))

$$\sigma(x) = \frac{1}{1 + e^{-x}}$$

Calculation:

  • a₁[0] = 1/(1 + e^(-0.45)) = 1/(1 + 0.6376) = 0.611
  • a₁[1] = 1/(1 + e^(-0.30)) = 1/(1 + 0.7408) = 0.574

$$\mathbf{a}_1 = \begin{bmatrix} 0.611 & 0.574 \end{bmatrix}$$

Step 2: Forward Pass - Output Layer

Linear Transformation (z₂ = a₁ · W₂ + b₂)

$$z_2 = \begin{bmatrix} 0.611 & 0.574 \end{bmatrix} \cdot \begin{bmatrix} 0.6 \\ -0.1 \end{bmatrix} + 0.2$$

Calculation:

z₂ = (0.611 × 0.6) + (0.574 × -0.1) + 0.2

z₂ = 0.3666 - 0.0574 + 0.2 = 0.509

Output Activation (ŷ = sigmoid(z₂))

$$\hat{y} = \sigma(0.509) = \frac{1}{1 + e^{-0.509}} = \frac{1}{1 + 0.6013} = \mathbf{0.625}$$

Step 3: Compute Loss

Mean Squared Error

$$\mathcal{L} = (y - \hat{y})^2 = (1.0 - 0.625)^2 = 0.375^2 = \mathbf{0.141}$$

Our prediction (0.625) is off from the target (1.0) by 0.375, resulting in a loss of 0.141.

Step 4: Backward Pass - Output Layer

Output Layer Error (δ₂)

$$\delta_2 = (\hat{y} - y) \cdot \sigma'(\hat{y})$$

$$\sigma'(a) = a(1 - a)$$

Calculation:

δ₂ = (0.625 - 1.0) × 0.625 × (1 - 0.625)

δ₂ = -0.375 × 0.625 × 0.375

δ₂ = -0.375 × 0.234 = -0.088

Note: Negative error means we need to increase the output.

Step 5: Backward Pass - Hidden Layer

Hidden Layer Error (δ₁)

$$\delta_1 = (W_2^T \cdot \delta_2) \odot \sigma'(a_1)$$

Calculation:

First, propagate error back through W₂:

$$W_2^T \cdot \delta_2 = \begin{bmatrix} 0.6 \\ -0.1 \end{bmatrix} \cdot (-0.088) = \begin{bmatrix} -0.053 \\ 0.009 \end{bmatrix}$$

Then multiply element-wise with sigmoid derivative:

  • σ'(a₁[0]) = 0.611 × (1 - 0.611) = 0.237
  • σ'(a₁[1]) = 0.574 × (1 - 0.574) = 0.245

$$\delta_1 = \begin{bmatrix} -0.053 \times 0.237 \\ 0.009 \times 0.245 \end{bmatrix} = \begin{bmatrix} -0.013 \\ 0.002 \end{bmatrix}$$

Step 6: Weight Updates

Update W₂ (Hidden → Output)

$$\frac{\partial \mathcal{L}}{\partial W_2} = a_1^T \cdot \delta_2 = \begin{bmatrix} 0.611 \\ 0.574 \end{bmatrix} \cdot (-0.088) = \begin{bmatrix} -0.054 \\ -0.050 \end{bmatrix}$$

$$W_2^{\text{new}} = W_2 - \alpha \cdot \frac{\partial \mathcal{L}}{\partial W_2}$$

$$W_2^{\text{new}} = \begin{bmatrix} 0.6 \\ -0.1 \end{bmatrix} - 0.1 \cdot \begin{bmatrix} -0.054 \\ -0.050 \end{bmatrix} = \begin{bmatrix} 0.605 \\ -0.095 \end{bmatrix}$$

Update b₂ (Output Bias)

$$b_2^{\text{new}} = b_2 - \alpha \cdot \delta_2 = 0.2 - 0.1 \cdot (-0.088) = 0.2 + 0.009 = \mathbf{0.209}$$

Update W₁ (Input → Hidden)

$$\frac{\partial \mathcal{L}}{\partial W_1} = X^T \cdot \delta_1 = \begin{bmatrix} 1.0 \\ 0.5 \end{bmatrix} \cdot \begin{bmatrix} -0.013 & 0.002 \end{bmatrix}$$

$$= \begin{bmatrix} -0.013 & 0.002 \\ -0.006 & 0.001 \end{bmatrix}$$

$$W_1^{\text{new}} = \begin{bmatrix} 0.5 & 0.2 \\ -0.3 & 0.4 \end{bmatrix} - 0.1 \cdot \begin{bmatrix} -0.013 & 0.002 \\ -0.006 & 0.001 \end{bmatrix} = \begin{bmatrix} 0.501 & 0.200 \\ -0.299 & 0.400 \end{bmatrix}$$

Update b₁ (Hidden Bias)

$$b_1^{\text{new}} = \begin{bmatrix} 0.1 \\ -0.1 \end{bmatrix} - 0.1 \cdot \begin{bmatrix} -0.013 \\ 0.002 \end{bmatrix} = \begin{bmatrix} 0.101 \\ -0.100 \end{bmatrix}$$

Before vs. After Weight Update
Parameter Before After Change
W₂[0] 0.600 0.605 +0.005
W₂[1] -0.100 -0.095 +0.005
b₂ 0.200 0.209 +0.009
Loss 0.141 ~0.135 (next iteration) Decreasing ✓

Result: After this single iteration, the weights have been adjusted to reduce the error. With thousands more iterations, the network will learn to predict accurately!

4.5 Understanding Loss Functions: Binary Cross-Entropy vs MSE

Why Loss Functions Matter

The choice of loss function fundamentally affects how your neural network learns. Let's understand why Binary Cross-Entropy (BCE) is preferred over Mean Squared Error (MSE) for classification tasks.

Binary Cross-Entropy Formula

For a single training example:

$$L_{BCE} = -[y \log(\hat{y}) + (1-y) \log(1-\hat{y})]$$

Where:

  • y: True label (0 or 1)
  • ŷ: Predicted probability (0 to 1)

Step-by-Step Breakdown

Case 1: When y = 1 (True label is "positive")

The formula simplifies to: L = -log(ŷ)

  • If ŷ = 1.0 (confident and correct): L = 0
  • If ŷ = 0.5 (uncertain): L = 0.693
  • If ŷ = 0.1 (confident but wrong): L = 2.303 (high penalty!)

Case 2: When y = 0 (True label is "negative")

The formula simplifies to: L = -log(1 - ŷ)

  • If ŷ = 0.0 (confident and correct): L = 0
  • If ŷ = 0.5 (uncertain): L = 0.693
  • If ŷ = 0.9 (confident but wrong): L = 2.303 (high penalty!)

Intuition: Why BCE Works Better

Key Insight: BCE heavily penalizes confident wrong predictions, which provides strong gradients that guide the network to correct itself quickly.

Maximum Likelihood Connection

Binary Cross-Entropy comes from maximum likelihood estimation. If we model the output as a Bernoulli distribution:

$$P(y|\hat{y}) = \hat{y}^y (1-\hat{y})^{1-y}$$

Taking the negative log gives us BCE! This means minimizing BCE is equivalent to maximizing the likelihood of the true labels.

Numerical Comparison

0.9 0.105 0.010 -1.111 -0.200

Notice: When the prediction is very wrong (ŷ=0.1 for y=1), BCE provides a much stronger gradient (-10.0) than MSE (-1.8). This leads to faster learning!

Why MSE Fails for Classification

The Sigmoid Saturation Problem

When using MSE with sigmoid outputs:

  • Sigmoid saturates (flat regions) when input is very positive or negative
  • In saturated regions, gradient ≈ 0 (vanishing gradient)
  • MSE gradients become even smaller: ∂MSE/∂ŷ · σ'(z) ≈ 0
  • Network learns very slowly or gets stuck

BCE solves this: The 1/ŷ term in BCE's gradient cancels out the sigmoid's derivative, maintaining strong gradients even in saturated regions!

Practical Takeaway

Use Binary Cross-Entropy for classification problems because:

  1. It has a probabilistic interpretation (maximum likelihood)
  2. It provides stronger gradients for wrong predictions
  3. It avoids the sigmoid saturation problem
  4. It leads to faster and more stable convergence

5. Training Process Flowchart

This flowchart illustrates the complete neural network training pipeline from data input to final model:

Step-by-Step Explanation

Step Description Purpose
1. Input Data Load training dataset (X, y) Provide examples for the network to learn from
2. Initialize Random weights with Xavier/He initialization[5] Break symmetry, enable learning
3. Forward Pass Compute predictions layer by layer Transform inputs into outputs
4. Compute Output Final layer activation ŷ Get network's current prediction
5. Calculate Loss Measure prediction error Quantify how wrong the network is
6. Backpropagation Compute gradients via chain rule Determine how to adjust weights
7. Update Weights Gradient descent step Improve weights to reduce error
8. Check Convergence Has loss stabilized? Determine if training is complete

💡 Convergence Criteria

Training stops when:

  • Loss plateau: Change in loss < threshold for N consecutive epochs
  • Max epochs reached: Pre-set iteration limit
  • Early stopping: Validation loss starts increasing (overfitting)
  • Gradient vanishing: Gradients become too small to cause meaningful updates

import numpy as np

class NeuralNetwork:
    """
    Feedforward neural network with backpropagation.

    Example:
        nn = NeuralNetwork([2, 4, 1], learning_rate=0.5)
        nn.train(X, y, epochs=10000)
        predictions = nn.predict(X)
    """

    def __init__(self, layer_sizes, learning_rate=0.01):
        """
        Initialize network.

        Args:
            layer_sizes: List [input_dim, hidden1, ..., output_dim]
            learning_rate: Gradient descent step size
        """
        self.layer_sizes = layer_sizes
        self.learning_rate = learning_rate
        self.weights = []
        self.biases = []
        self._initialize_parameters()

    def _initialize_parameters(self):
        """Xavier initialization for weights."""
        for i in range(len(self.layer_sizes) - 1):
            n_in = self.layer_sizes[i]
            n_out = self.layer_sizes[i + 1]

            # Xavier initialization
            W = np.random.randn(n_in, n_out) * np.sqrt(2.0 / n_in)
            b = np.zeros((1, n_out))

            self.weights.append(W)
            self.biases.append(b)

    def sigmoid(self, z):
        """Sigmoid activation: σ(z) = 1/(1+e^(-z))"""
        return 1 / (1 + np.exp(-np.clip(z, -500, 500)))

    def sigmoid_derivative(self, a):
        """Derivative: σ'(z) = σ(z)(1-σ(z))"""
        return a * (1 - a)

    def forward(self, X):
        """
        Forward propagation.

        Returns:
            activations: List of activations [a0, a1, ..., aL]
            z_values: List of pre-activation values
        """
        activations = [X]
        z_values = []

        for W, b in zip(self.weights, self.biases):
            z = np.dot(activations[-1], W) + b
            a = self.sigmoid(z)
            z_values.append(z)
            activations.append(a)

        return activations, z_values

    def compute_loss(self, y_true, y_pred):
        """Mean squared error loss."""
        return np.mean((y_pred - y_true) ** 2)

    def backward(self, X, y, activations, z_values):
        """
        Backpropagation to compute gradients.

        Returns:
            weight_grads: Gradients for each weight matrix
            bias_grads: Gradients for each bias vector
        """
        m = X.shape[0]  # Number of samples
        num_layers = len(self.weights)

        # Output layer error
        delta = (activations[-1] - y) * self.sigmoid_derivative(activations[-1])
        deltas = [delta]

        # Backpropagate through hidden layers
        for l in range(num_layers - 2, -1, -1):
            delta = np.dot(deltas[0], self.weights[l+1].T) * \
                    self.sigmoid_derivative(activations[l+1])
            deltas.insert(0, delta)

        # Compute weight and bias gradients
        weight_grads = []
        bias_grads = []

        for l in range(num_layers):
            dW = np.dot(activations[l].T, deltas[l]) / m
            db = np.sum(deltas[l], axis=0, keepdims=True) / m
            weight_grads.append(dW)
            bias_grads.append(db)

        return weight_grads, bias_grads

    def update_parameters(self, weight_grads, bias_grads):
        """Gradient descent update."""
        for i in range(len(self.weights)):
            self.weights[i] -= self.learning_rate * weight_grads[i]
            self.biases[i] -= self.learning_rate * bias_grads[i]

    def train(self, X, y, epochs=1000, verbose=True):
        """
        Train the neural network.

        Args:
            X: Input data [n_samples, n_features]
            y: Target labels [n_samples, n_outputs]
            epochs: Number of training iterations
            verbose: Print progress

        Returns:
            losses: List of loss values per epoch
        """
        losses = []

        for epoch in range(epochs):
            # Forward pass
            activations, z_values = self.forward(X)

            # Compute loss
            loss = self.compute_loss(y, activations[-1])
            losses.append(loss)

            # Backward pass
            weight_grads, bias_grads = self.backward(X, y, activations, z_values)

            # Update weights
            self.update_parameters(weight_grads, bias_grads)

            # Print progress
            if verbose and (epoch % (epochs // 10) == 0 or epoch == epochs - 1):
                print(f"Epoch {epoch:4d}: Loss = {loss:.6f}")

        return losses

    def predict(self, X):
        """Make predictions on new data."""
        activations, _ = self.forward(X)
        return activations[-1]

📚 Why XOR?

The XOR problem is a classic demonstration because it's linearly inseparable—no single straight line can separate the classes. This proves that hidden layers are necessary for learning non-linear patterns.

A perceptron (single layer) cannot solve XOR, but a neural network with even one hidden layer can!

7. Variants & Extensions

Neural Network Architectures

🖼️ Convolutional Neural Networks (CNNs)

Key Components:

  • Convolutional layers (feature extraction)
  • Pooling layers (dimensionality reduction)
  • Shared weights (translation invariance)

Best for: Images, spatial data

Example: Image classification, object detection

Pioneering work: LeNet[4], AlexNet, ResNet

🔄 Recurrent Neural Networks (RNNs)

Key Components:

  • Hidden state memory
  • Sequential processing
  • Weight sharing across time steps

Best for: Time series, text sequences

Example: Language modeling, speech recognition

Variants: LSTM (Long Short-Term Memory), GRU (Gated Recurrent Unit)

🤖 Transformers

Key Components:

  • Self-attention mechanism
  • Parallel processing (no recurrence)
  • Positional encodings

Best for: NLP, long sequences

Example: BERT, GPT, machine translation

Advantage: Handles long-range dependencies better than RNNs

🔧 Autoencoders

Key Components:

  • Encoder (compress to latent space)
  • Decoder (reconstruct from latent)
  • Unsupervised learning

Best for: Dimensionality reduction, denoising

Example: Anomaly detection, data compression

Variants: Variational Autoencoders (VAEs)

Optimization Techniques

📊 Batch Normalization

What it does: Normalizes layer inputs to have zero mean and unit variance

Benefits:

  • Stabilizes training
  • Allows higher learning rates
  • Reduces sensitivity to initialization

Formula: \(\hat{x} = \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}}\)

🎲 Dropout

What it does: Randomly "drops" (sets to 0) neurons during training with probability \(p\)

Benefits:

  • Prevents overfitting
  • Forces redundant representations
  • Acts like ensemble learning

Typical values: \(p = 0.5\) for hidden layers, \(p = 0.2\) for input

📉 Learning Rate Scheduling

What it does: Gradually decreases learning rate during training

Strategies:

  • Step decay: Reduce by factor every N epochs
  • Exponential: \(\alpha_t = \alpha_0 e^{-kt}\)
  • Cosine annealing: Smooth cosine curve

Benefit: Fine-tune weights in later epochs

⚖️ Regularization (L1/L2)

What it does: Adds penalty term to loss function

L2 (Ridge): \(\mathcal{L}_{\text{total}} = \mathcal{L} + \lambda \sum w^2\)

L1 (Lasso): \(\mathcal{L}_{\text{total}} = \mathcal{L} + \lambda \sum |w|\)

Effect:

  • L2: Encourages small weights
  • L1: Encourages sparse weights (feature selection)

Comparison Table

Architecture Input Type Strengths Weaknesses
Feedforward Tabular/Vector Simple, fast, interpretable Limited feature learning, no temporal/spatial awareness
CNN Images/Grids Translation invariance, parameter sharing Needs lots of data, struggles with rotation
RNN/LSTM Sequences Temporal dependencies, variable length Slow (sequential), vanishing gradient
Transformer Sequences/Any Parallel, long-range dependencies, attention Very large models, high memory/compute cost

⚠️ Choosing the Right Architecture

Start simple: Try a feedforward network first. Only add complexity (CNNs, RNNs, Transformers) if your data has specific structure (spatial, temporal).

Rule of thumb:

  • Tabular data → Feedforward NN
  • Images → CNN
  • Text/Time series → Transformer or LSTM
  • Graphs → Graph Neural Network (GNN)

Foundational Papers

  1. McCulloch, W. S., & Pitts, W. (1943). "A logical calculus of the ideas immanent in nervous activity." Bulletin of Mathematical Biophysics, 5(4), 115-133.
    First mathematical model of biological neurons, laying the foundation for artificial neural networks.
  2. Rosenblatt, F. (1958). "The perceptron: A probabilistic model for information storage and organization in the brain." Psychological Review, 65(6), 386-408.
    Introduced the perceptron learning algorithm, the first trainable neural network.
  3. Rumelhart, D. E., Hinton, G. E., & Williams, R. J. (1986). "Learning representations by back-propagating errors." Nature, 323(6088), 533-536.
    Popularized backpropagation for training multilayer networks, enabling deep learning.
  4. LeCun, Y., Bottou, L., Bengio, Y., & Haffner, P. (1998). "Gradient-based learning applied to document recognition." Proceedings of the IEEE, 86(11), 2278-2324.
    Introduced LeNet, demonstrating convolutional neural networks for handwritten digit recognition.
  5. Glorot, X., & Bengio, Y. (2010). "Understanding the difficulty of training deep feedforward neural networks." AISTATS 2010.
    Analyzed vanishing/exploding gradients and introduced Xavier initialization.
  6. Kingma, D. P., & Ba, J. (2015). "Adam: A method for stochastic optimization." ICLR 2015.
    Introduced the Adam optimizer, combining momentum and adaptive learning rates.
  7. Goodfellow, I., Bengio, Y., & Courville, A. (2016). Deep Learning. MIT Press.
    Comprehensive textbook covering neural network fundamentals, optimization, and advanced architectures.
    Available free: https://www.deeplearningbook.org/
